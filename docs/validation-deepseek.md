## 追記（同日稍晚）：思考型模型把解讀截斷

使用者在網頁上用 2026-10-29 13:35 男 跑八字解讀，只出現半段總論，其餘五段「缺漏」。重現後：`finish_reason = length`、`output_tokens = 2500`，而回覆裡有 `reasoning_content`——**DeepSeek V4.1-Flash 是思考型模型，推理 token 也算在 `max_tokens` 裡**，2500 的預算大半被思考吃掉。

修法：
- `READING_MAX_TOKENS` 預設 2500 → 8000（只付實際產生的 token，不會因為上限高就變貴）
- 偵測到截斷（OpenAI 相容 `finish_reason=length`、Anthropic `stop_reason=max_tokens`）自動加倍重試一次；串流被截斷則改非串流重試，畫面以 `done` 事件為準
- 仍截斷時寫進 `warnings` 提示調高預算

順便抓到：模型寫「盤面未載性別」——它是對的，性別只在方向規則裡用到，沒放進盤面事實。已加 `bazi.gender` / `ziwei.gender`。
